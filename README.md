# SkyFinder

여행 가능한 날짜 범위와 여행 일수를 입력하면 일본 왕복 항공권 후보를 비교해 **저렴한 일정 Top 5**를 보여주는 웹 프로젝트입니다.

출발일을 하나씩 바꿔가며 검색하지 않아도, 가능한 일정들을 한 번에 비교할 수 있도록 만들었습니다.

> 항공권과 가격 데이터는 Python으로 생성한 시뮬레이션 데이터입니다. 실제 항공권 가격이나 예약 정보와는 관련이 없습니다.

## 프로젝트를 만든 이유

여행 날짜가 정해져 있지 않은 경우에는 항공권이 가장 저렴한 시점을 찾기 위해 출발일과 귀국일을 계속 바꿔가며 검색해야 합니다.

SkyFinder는 반대로 **여행 가능한 기간을 먼저 입력하고, 그 안에서 저렴한 일정을 찾는 방식**으로 만들었습니다.

사용자는 다음 세 가지 조건을 선택합니다.

* 목적지
* 여행 일수
* 여행 가능한 날짜 범위

조건에 맞는 왕복 항공권 후보를 비교한 뒤 가격과 일정이 괜찮은 5개를 골라 달력과 항공권 카드로 보여줍니다.

## 주요 기능

* 일본 전체 또는 특정 지역 검색
* 1~15일 여행 기간 선택
* 여행 가능한 날짜 범위 설정
* LCC / FSC 항공사 필터
* 검색 조건에 맞는 왕복 일정 비교
* 가격을 기준으로 Top 5 일정 추천
* 비슷한 목적지와 출발일이 몰리지 않도록 추천 결과 조정
* 추천 일정을 달력과 항공권 카드로 확인
* PC / 모바일 반응형 지원

별도의 백엔드나 데이터베이스는 사용하지 않았습니다.

Python으로 항공권 데이터를 미리 생성해 JSON으로 저장하고, 프론트엔드에서 검색에 필요한 파일만 불러와 처리합니다.

## 검색 방식

```text
검색 조건 입력
        ↓
필요한 JSON 데이터 로드
        ↓
날짜 범위에 맞는 일정 필터링
        ↓
항공사 조건 적용
        ↓
가격 기준으로 후보 정렬
        ↓
목적지와 출발일 중복을 고려해 Top 5 선정
        ↓
달력 + 항공권 카드로 표시
```

`일본 전체`로 검색할 경우 한 지역의 항공권만 결과에 몰리지 않도록 서로 다른 목적지를 우선해서 선택합니다.

출발일 역시 너무 가까운 일정이 반복되지 않도록 간격을 두고 선택하며, 조건에 맞는 후보가 부족한 경우에만 간격을 줄입니다.

## 데이터

항공권 데이터는 여행 일수와 출발 월을 기준으로 나누어 저장했습니다.

```text
public/data/
├── airlines.json
├── destinations.json
├── manifest.json
└── offers/
    ├── 01/
    ├── 02/
    ├── ...
    └── 15/
```

예를 들어 **5박 6일 / 2026년 1월 출발** 항공권은 다음 파일에 저장됩니다.

```text
/data/offers/06/2026-01.json
```

필요한 월의 데이터만 불러오기 때문에 전체 항공권 데이터를 한 번에 로드하지 않습니다.

데이터 생성 규칙과 JSON 구조는 [DATA.md](./DATA.md)에 정리했습니다.

## 로컬 실행

```bash
git clone https://github.com/sugwon065/flight-v2.git
cd flight-v2

npm install
npm run dev
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:5173
```

Node.js 18 이상이 필요합니다.

## 데이터 생성

항공권 시뮬레이션 데이터는 Python 스크립트로 생성합니다.

```bash
python scripts/generate_data.py
```

고정된 seed를 사용하기 때문에 같은 조건으로 실행하면 동일한 데이터를 다시 생성할 수 있습니다.
