# SkyFinder

여행 가능한 기간을 입력하면 일본 지역별 왕복 항공권 후보를 비교하고, 저렴한 지역 5개를 선택한 뒤 해당 지역의 저렴한 여행 기간 5개를 보여주는 웹 프로젝트입니다.

> 이 프로젝트의 항공권 정보와 가격은 공개 가격 조사값으로 보정한 Python 시뮬레이션 데이터입니다. 실제 항공권 가격 및 예약 정보와 다릅니다.

> 항공권과 가격 데이터는 Python으로 생성한 시뮬레이션 데이터입니다. 실제 항공권 가격이나 예약 정보와는 관련이 없습니다.

## 프로젝트를 만든 이유

여행 날짜가 정해져 있지 않은 경우에는 항공권이 가장 저렴한 시점을 찾기 위해 출발일과 귀국일을 계속 바꿔가며 검색해야 합니다.

SkyFinder는 반대로 **여행 가능한 기간을 먼저 입력하고, 그 안에서 저렴한 일정을 찾는 방식**으로 만들었습니다.

검색 결과는 저렴한 도시 5개의 사진 카드로 표시합니다. 도시를 선택하면 해당 도시의 모든 가능한 출발일을 가격 달력으로 비교하고, 저렴한 여행 일정 5개와 선택한 왕복 정보를 확인할 수 있습니다.

## 주요 기능

- 상단에서 여행일수·가능 기간·검색할 도시·항공사 유형 입력
- 지역별 최저가를 비교해 저렴한 도시 5개 추천
- 도시 선택 후 해당 도시의 날짜별 왕복 가격 달력 표시
- 파랑 → 연한 파랑 → 옅은 파랑 → 연한 분홍 → 분홍의 5단계 상대 가격 표시
- 검색 기간 전체의 서로 다른 가격 순위를 기준으로 색상을 배정해 월 이동 시 같은 가격은 같은 색으로 표시
- 저렴한 여행 일정 5개는 왕관으로 표시하고, 달력과 추천 카드에서 선택 가능
- 선택한 출국·귀국일, 항공사, 공항, 왕복 총액 표시
- 검색 결과 조건과 입력 중인 조건을 구분하고 재검색 시 도시 선택 초기화
- 특정 도시 검색은 그 도시의 가격 달력으로 바로 이동
- 월 이동 범위 제한, 귀국일이 가능 기간을 벗어나는 출발일 비활성화
- 반응형 도시 카드·가격 달력, 키보드 선택 및 이용 방법 안내
- 로컬 사진과 저작자·라이선스 출처 표시

별도의 백엔드나 데이터베이스는 사용하지 않았습니다.

Python으로 항공권 데이터를 미리 생성해 JSON으로 저장하고, 프론트엔드에서 검색에 필요한 파일만 불러와 처리합니다.

## 검색 방식

```text
사용자 조건 입력
  ↓
여행 일수와 출발월에 맞는 JSON 로드
  ↓
출발일·귀국일이 검색 범위 안에 있는 후보 필터링
  ↓
항공사 유형에 맞는 왕복 항공권 선택
  ↓
지역마다 가장 저렴한 일정 하나 선택
  ↓
가격이 낮은 도시 5개를 사진 카드로 표시
  ↓
지역 클릭
  ↓
해당 도시의 날짜별 가격 달력과 저렴한 여행 일정 5개 표시
```

일본 전체 검색은 지역별 최저가를 비교합니다. 특정 지역 검색은 기간 5개를 바로 표시합니다. 가격이 같으면 출발일, 목적지 ID 순으로 정렬합니다. 기간이 겹쳐도 포함하며 후보가 5개 미만이면 있는 결과만 표시합니다. 지역 선택 시 이미 불러온 후보를 재사용합니다.

## 데이터

항공권 데이터는 여행 일수와 출발 월을 기준으로 나누어 저장했습니다.

```text
public/data/
├── airlines.json
├── destinations.json
├── manifest.json
└── offers/
    ├── 01/
    │   ├── 2026-10.json
    │   └── ...
    ├── 02/
    ├── ...
    └── 15/
```

항공권 후보는 `offers/{여행일수}/{출발월}.json`에 저장됩니다. 예를 들어 5박 6일 여행의 2026년 10월 후보는 다음 파일에서 불러옵니다.

```text
/data/offers/06/2026-10.json
```

필요한 월의 데이터만 불러오기 때문에 전체 항공권 데이터를 한 번에 로드하지 않습니다.

데이터 생성 규칙과 JSON 구조는 [DATA.md](./DATA.md)에 정리했습니다.

## 로컬 실행

```bash
git clone https://github.com/sugwon065/flight-v2.git
cd flight-v2

npm install
npm run dev
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:5173
```

Node.js 18 이상이 필요합니다.

## 데이터 생성

항공권 시뮬레이션 데이터는 Python 스크립트로 생성합니다.

```bash
python scripts/generate_data.py
```

고정된 seed를 사용하기 때문에 같은 조건으로 실행하면 동일한 데이터를 다시 생성할 수 있습니다.

## 한계

- 실제 항공사 API와 연결되어 있지 않습니다.
- 가격은 실제 예약 가격이 아닌 시뮬레이션 값입니다.
- 결제와 항공권 예약 기능은 제공하지 않습니다.
- 데이터 범위와 기본 검색 기간은 2026.10.01 ~ 2027.07.31입니다. 출국과 귀국이 모두 이 범위 안에 있는 일정을 생성하며, 생성기와 화면은 `src/services/travelDateRange.json`을 함께 사용합니다.
