# SkyFinder

여행 가능한 기간을 입력하면 일본 지역별 왕복 항공권 후보를 비교하고, 다양한 목적지와 출발일을 고려한 최저가 일정 Top 5를 보여주는 웹 프로젝트입니다.

> 이 프로젝트의 항공권 정보와 가격은 Python으로 임의 생성한 시뮬레이션 데이터입니다. 실제 항공권 가격 및 예약 정보와 다릅니다.

## 배포 주소

- 웹사이트: [https://flight-v2.vercel.app](https://flight-v2.vercel.app)
- GitHub: [https://github.com/sugwon065/flight-v2](https://github.com/sugwon065/flight-v2)

## 프로젝트 배경

기존 항공권 검색 서비스는 사용자가 출발일과 귀국일을 정한 뒤 가격을 확인하는 방식입니다. 여행 날짜를 유연하게 조정할 수 있는 사용자는 가장 저렴한 기간을 찾기 위해 날짜를 바꾸며 여러 번 검색해야 합니다.

SkyFinder는 다음 세 가지 정보만으로 검색 기간 안의 가능한 일정을 비교합니다.

1. 목적지
2. 여행 일수
3. 여행 가능한 날짜 범위

검색 결과는 최저가 후보를 달력에 시각화하고, 항공권 카드와 연결해 지역·기간·가격을 한눈에 비교할 수 있도록 구성했습니다.

## 주요 기능

- 일본 전체 또는 특정 목적지 선택
- 1일부터 15일까지의 여행 일수 선택
- 여행 가능한 시작일과 종료일 선택
- 전체·저비용 항공사(LCC)·일반 항공사(FSC) 필터
- 검색 기간에 포함되는 왕복 일정 비교
- 목적지와 출발일이 지나치게 겹치지 않는 Top 5 추천
- 최저가 기간을 두 달 달력에 순위별 색상으로 표시
- 달력의 순위·지역 배지를 누르면 해당 항공권 카드로 이동
- 항공사 로고, 왕복 시간, 공항, 가격 정보 표시
- 프로젝트 설명·사용법·알고리즘 안내 모달
- PC 및 모바일 반응형 화면

## 검색 흐름

```text
사용자 조건 입력
  ↓
여행 일수와 출발월에 맞는 JSON 로드
  ↓
출발일·귀국일이 검색 범위 안에 있는 후보 필터링
  ↓
항공사 유형에 맞는 왕복 항공권 선택
  ↓
가격과 할인율을 반영해 후보 점수 계산
  ↓
목적지 중복과 가까운 출발일을 줄여 Top 5 선정
  ↓
달력과 항공권 카드로 결과 표시
```

일본 전체 검색에서는 목적지가 서로 다른 후보를 우선합니다. 출발일 간격 조건으로 다양한 기간을 선택하며, 후보가 부족하면 간격을 단계적으로 완화합니다.

## 데이터 구조

```text
public/data/
├── airlines.json
├── destinations.json
├── manifest.json
└── offers/
    ├── 01/
    │   ├── 2026-01.json
    │   └── ...
    ├── 02/
    └── 15/
```

항공권 후보는 `offers/{여행일수}/{출발월}.json`에 저장됩니다. 예를 들어 5박 6일 여행의 2026년 1월 후보는 다음 파일에서 불러옵니다.

```text
/data/offers/06/2026-01.json
```

데이터 생성 규칙과 JSON 형식은 [DATA.md](./DATA.md)에서 확인할 수 있습니다.

## 로컬 실행

### 요구 사항

- Node.js 18 이상
- npm

### 설치 및 실행

```bash
git clone https://github.com/sugwon065/flight-v2.git
cd flight-v2
npm install
npm run dev
```

개발 서버가 실행되면 브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:5173
```

## 프로덕션 빌드

```bash
npm run build
npm run preview
```

빌드 결과는 `dist/` 폴더에 생성됩니다.

## 데이터 다시 생성하기

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
python scripts/generate_data.py
```

생성기는 고정 시드를 사용하므로 같은 규칙에서는 동일한 결과를 다시 만들 수 있습니다.
